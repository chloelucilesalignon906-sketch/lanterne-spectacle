# Banque 1.3.0

Branche lue par Banque (1.3.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Banque-1.3.0.banquemaj` est la mise à jour signée qui s’installe depuis Banque.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Banque-Installation-Mac-1.3.0.zip](Banque-Installation-Mac-1.3.0.zip)
- [Banque-Installation-Mac-Intel-1.3.0.zip](Banque-Installation-Mac-Intel-1.3.0.zip)
- [Banque-Installation-Windows-1.3.0.zip](Banque-Installation-Windows-1.3.0.zip)

Nouveautés :

- Mises à jour depuis GitHub : Banque prévient à l'ouverture qu'une nouvelle version existe et l'installe en un clic
- Réglages › Mises à jour : chercher maintenant, ne plus chercher à l'ouverture, revenir à la version d'avant
- Plusieurs listes d'intervenants nommées (depuis 1.2.0)
