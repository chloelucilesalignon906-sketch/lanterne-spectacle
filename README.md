# Écran Hall 1.4.1

Branche lue par Écran Hall (1.4.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Ecran-Hall-1.4.1.ecranhallmaj` est la mise à jour signée qui s’installe depuis Écran Hall.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Ecran-Hall-Installation-Mac-1.4.1.zip](Ecran-Hall-Installation-Mac-1.4.1.zip)
- [Ecran-Hall-Installation-Mac-Intel-1.4.1.zip](Ecran-Hall-Installation-Mac-Intel-1.4.1.zip)
- [Ecran-Hall-Installation-Windows-1.4.1.zip](Ecran-Hall-Installation-Windows-1.4.1.zip)

Nouveautés :

- Pause du diaporama (écrans cochés ou un seul écran) et diapo choisie montrée tout de suite (bouton « À l’écran » sur une vignette)
- Vidéos : format vérifié (HEVC, ProRes, H.264 10 bits signalés) ; une vidéo que la télé ne lit pas affiche la raison puis passe à la suite
