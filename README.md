# Lanterne Tableau de bord 1.5.0

Branche lue par Lanterne Tableau de bord (1.4.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Lanterne-Tableau-de-bord-1.5.0.tableaumaj` est la mise à jour signée qui s’installe depuis le Tableau de bord.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Lanterne-Tableau-de-bord-Installation-Mac-1.5.0.zip](Lanterne-Tableau-de-bord-Installation-Mac-1.5.0.zip)
- [Lanterne-Tableau-de-bord-Installation-Mac-Intel-1.5.0.zip](Lanterne-Tableau-de-bord-Installation-Mac-Intel-1.5.0.zip)
- [Lanterne-Tableau-de-bord-Installation-Windows-1.5.0.zip](Lanterne-Tableau-de-bord-Installation-Windows-1.5.0.zip)

Nouveautés :

- Onglet Surveillance (Cmd/Ctrl+L) : les caméras Mevo en NDI ajoutées toutes seules, d’autres caméras NDI au choix
- Onglet Personnalisé (Cmd/Ctrl+P) : on choisit les caméras et les sorties des logiciels Lanterne à afficher, dans l’ordre voulu, en 1 à 4 colonnes
- Les deux nouveaux onglets aussi sur le téléphone
