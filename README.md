# Écran Hall 1.4.0

Branche lue par Écran Hall (1.4.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Ecran-Hall-1.4.0.ecranhallmaj` est la mise à jour signée qui s’installe depuis Écran Hall.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Ecran-Hall-Installation-Mac-1.4.0.zip](Ecran-Hall-Installation-Mac-1.4.0.zip)
- [Ecran-Hall-Installation-Mac-Intel-1.4.0.zip](Ecran-Hall-Installation-Mac-Intel-1.4.0.zip)
- [Ecran-Hall-Installation-Windows-1.4.0.zip](Ecran-Hall-Installation-Windows-1.4.0.zip)

Nouveautés :

- Écrans Samsung pro sans boîtier (Smart Signage, par ex. QE75T) : bouton « + Samsung », l’écran ouvre une page servie par cet ordinateur
- Mises à jour depuis GitHub : bandeau quand une nouvelle version existe, retour possible
