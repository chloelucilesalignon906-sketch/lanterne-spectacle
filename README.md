# Lanterne Tableau de bord 1.6.0

Branche lue par Lanterne Tableau de bord (1.4.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Lanterne-Tableau-de-bord-1.6.0.tableaumaj` est la mise à jour signée qui s’installe depuis le Tableau de bord.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Lanterne-Tableau-de-bord-Installation-Mac-1.6.0.zip](Lanterne-Tableau-de-bord-Installation-Mac-1.6.0.zip)
- [Lanterne-Tableau-de-bord-Installation-Mac-Intel-1.6.0.zip](Lanterne-Tableau-de-bord-Installation-Mac-Intel-1.6.0.zip)
- [Lanterne-Tableau-de-bord-Installation-Windows-1.6.0.zip](Lanterne-Tableau-de-bord-Installation-Windows-1.6.0.zip)

Nouveautés :

- Son des caméras : bouton 🔈 sur une caméra (Surveillance, Personnalisé ou en grand) pour écouter son son sur cet ordinateur, une caméra à la fois
- Le son continue dans les autres onglets ; volume et ✕ dans l’encadré vert en bas à droite, orange quand aucun son n’arrive
