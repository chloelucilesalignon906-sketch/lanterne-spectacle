# Écran Hall 1.4.4

Branche lue par Écran Hall (1.4.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Ecran-Hall-1.4.4.ecranhallmaj` est la mise à jour signée qui s’installe depuis Écran Hall.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Ecran-Hall-Installation-Mac-1.4.4.zip](Ecran-Hall-Installation-Mac-1.4.4.zip)
- [Ecran-Hall-Installation-Mac-Intel-1.4.4.zip](Ecran-Hall-Installation-Mac-Intel-1.4.4.zip)
- [Ecran-Hall-Installation-Windows-1.4.4.zip](Ecran-Hall-Installation-Windows-1.4.4.zip)

Nouveautés :

- Qeedji : la vidéo est maintenant tournée pour de bon (télé verticale et bouton ⟳) : Écran Hall la réencode déjà tournée avant l'envoi, sans le son. Rien à régler dans la console du Qeedji. L'envoi prend à peu près la durée de la vidéo.
