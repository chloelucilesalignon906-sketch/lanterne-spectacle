# Lanterne Tableau de bord 1.4.0

Branche lue par Lanterne Tableau de bord (1.4.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Lanterne-Tableau-de-bord-1.4.0.tableaumaj` est la mise à jour signée qui s’installe depuis le Tableau de bord.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Lanterne-Tableau-de-bord-Installation-Mac-1.4.0.zip](Lanterne-Tableau-de-bord-Installation-Mac-1.4.0.zip)
- [Lanterne-Tableau-de-bord-Installation-Mac-Intel-1.4.0.zip](Lanterne-Tableau-de-bord-Installation-Mac-Intel-1.4.0.zip)
- [Lanterne-Tableau-de-bord-Installation-Windows-1.4.0.zip](Lanterne-Tableau-de-bord-Installation-Windows-1.4.0.zip)

Nouveautés :

- Page téléphone : code QR (bouton Téléphone, Cmd/Ctrl+T), onglets Vue d’ensemble et Contrôle sur un téléphone du réseau, rien à installer
- Mises à jour depuis GitHub, en un clic, avec retour à la version d’avant
