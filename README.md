# Prise 1.5.0

Branche lue par Prise (1.5.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, les fichiers `.prisemaj` (signés) et les zips de l'appli s'installent depuis Prise (bandeau bleu, ou menu Prise › Rechercher une mise à jour…).

Première installation : installeur .dmg (ouvrir, glisser Prise dans Applications).

- Mac Apple Silicon : [Prise-1.5.0-Mac-Apple-Silicon.dmg](Prise-1.5.0-Mac-Apple-Silicon.dmg)
- Mac Intel : [Prise-1.5.0-Mac-Intel.dmg](Prise-1.5.0-Mac-Intel.dmg)

Nouveautés :

- Synchro son/image : Prise cale le son et l'image sur les morceaux les moins retardés par le réseau, plus de décalage qui change à chaque connexion
- Écoute au casque : l'image et le son sont joués ensemble
- Réglage « Synchro son / image » par caméra (onglet Enregistrement)
- Mises à jour en ligne : Prise regarde sur GitHub s'il existe une nouvelle version et l'installe en un clic
