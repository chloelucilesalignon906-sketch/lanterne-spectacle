# Banque 1.4.0

Branche lue par Banque (1.3.0 et plus) pour ses mises à jour : `derniere.json` annonce la dernière version, `Banque-1.4.0.banquemaj` est la mise à jour signée qui s’installe depuis Banque.

Première installation, ou nouveau moteur : zips complets ci-dessous (dézipper, puis suivre le LISEZMOI).

- [Banque-Installation-Mac-1.4.0.zip](Banque-Installation-Mac-1.4.0.zip)
- [Banque-Installation-Mac-Intel-1.4.0.zip](Banque-Installation-Mac-Intel-1.4.0.zip)
- [Banque-Installation-Windows-1.4.0.zip](Banque-Installation-Windows-1.4.0.zip)

Nouveautés :

- Onglets dans Ma banque : un par salle, par lieu (créer, renommer, glisser des fichiers dessus pour les y ranger)
- Les autres ordinateurs voient les onglets d'une banque principale ; récupérer depuis un onglet le crée aussi dans leur banque
